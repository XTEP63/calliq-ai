# Sources for the CallIQ presentation

External product descriptions were checked on 20 November 2026. The competitor slide describes each vendor's public product positioning; it is not a feature-by-feature procurement evaluation.

- NICE, [Enlighten AI for Customer Satisfaction](https://www.nice.com/products/enlighten-ai-customer-satisfaction-csat-2): analysis across interactions, supervisor and agent scorecards, coaching, real-time guidance.
- CallMiner, [Quality Management](https://callminer.com/solutions/quality-management): automated quality forms, agent and supervisor dashboards, coaching, prioritized review lists.
- Observe.AI, [Auto QA](https://www.observe.ai/post-interaction/auto-qa): automated QA, evidence, coaching, agent acknowledgement and dispute options.
- Duarte, [Effective presentation skills](https://www.duarte.com/blog/presenting/): one main idea per slide and audience-centered visual aids informed the slide structure.
- Nielsen Norman Group, [Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/): informed the Streamlit UX choice to show summary first and place full transcript and technical details behind an expander.
- [CallIQ implementation and validation](https://github.com/XTEP63/calliq-ai): source for statements about the MVP's current functions and limits.

Artwork in `assets/cover-wave.png` and `assets/blindspot-wave.png` was generated for this presentation with the built-in image generation tool. Neither image depicts a real customer interaction.
